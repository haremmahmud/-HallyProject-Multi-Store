​🇸🇦  (العربية)
​منصة تجارة إلكترونية متكاملة ونظام متعدد المتاجر (Multi-Store) يتيح للمستخدمين إنشاء متاجرهم وتطبيقاتهم الخاصة بكل سهولة وبدون خبرة برمجية، مرتبطة بمنصة Kasebox.
​رابط الموقع الرسمي: https://kasebox.dev


​🇮🇶  (کوردی)
​پلاتفۆرمێکی تەواوی تجارت و فرۆشگای ئۆنلاین و سیستەمێکی فرە-فرۆشگا (Multi-Store) کە ڕێگە بە بەکارهێنەران دەدات بە ئاسانی و بەبێ هیچ شارەزاییەکی پڕۆگرامسازی، فرۆشگا و ئەپڵیکەیشنی تایبەت بە خۆیان دروست بکەن، کە بەستراوەتەوە بە پلاتفۆرمی کازیبۆکس.
​لینکی فەرمی وێبسایت: https://kasebox.dev


​🇬🇧  (English)
​An integrated e-commerce platform and multi-store system that allows users to easily create their own stores and apps without any programming experience, connected to the Kasebox platform.
​Official Website: https://kasebox.dev
